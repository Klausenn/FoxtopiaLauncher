# Foxtopia Launcher Support

Foxtopia Launcher is published by **Klausenn (Foxtopia)**. Contact **[iratakano99@gmail.com](mailto:iratakano99@gmail.com)** for launcher support, account help, privacy requests or concerns about Foxtopia content and player conduct. You can write in English, Turkish or Polish.

## Report a problem

Include the launcher version, Windows version, the action that failed, and the full fox error code if one is shown. Describe what you expected and what happened. A screenshot can help; hide private chat, email addresses and account details first.

For a game issue, the in-game report flow lets you write a description, choose whether to include a sanitized recent log, preview the result and confirm submission. The launcher's diagnostic export saves a file locally; review it before attaching it to an email. Automatic crash summaries are separate from reports you choose to send. See the [privacy notice](PRIVACY.md) for the information each route processes.

Never send passwords, sign-in codes, access tokens, remembered-session/cache files, government identification or your complete launcher data folder. Support does not need these to begin investigating.

## Updates and installation

For the Microsoft Store edition, use Microsoft Store's library/update controls. Its application updates are managed by Microsoft Store. For the direct-download edition, use the launcher's update control or a newer installer from the [official releases](https://github.com/Klausenn/FoxtopiaLauncher/releases).

If an old direct-download version cannot find updates, close the launcher and install the current official version over the existing installation. Do not uninstall or delete your game/profile data as a first troubleshooting step. Back up files you want to keep before changing editions or manually removing data.

The launcher is free and does not include a Minecraft license. Internet access and a supported Foxtopia/Microsoft sign-in are needed for server features. The Store package targets Windows 11 build 22000 or newer, x64. Fabric and NeoForge are the supported Foxtopia client profiles; optional content must match the selected game version and loader.

## Accounts and privacy

Signing out does not delete a Foxtopia server account, its saved world progress or all local files. To request access, correction or deletion, email **[iratakano99@gmail.com](mailto:iratakano99@gmail.com)** with your player name, account type and what you want changed. Account control may need to be verified before private information is disclosed or changed. Do not send a password or identity document. Microsoft-account recovery and deletion must be handled through Microsoft's own account services.

## Content and player-conduct concerns

Do not use Foxtopia chat or skins to threaten, harass or expose another person's private information, or to share unlawful or abusive content. To report a concern to the Foxtopia operator, email the contact above with the player/content name, approximate time and a description. Include only evidence needed to identify the concern; avoid redistributing harmful material or unrelated private information. Foxtopia moderation can include reviewing the report, removing content or limiting server access. Reporting does not guarantee a particular outcome or immediate response.

For a Modrinth project's listing or files, also use that project's report controls on [Modrinth](https://modrinth.com/) so the platform can review content it controls. Optional content belongs to its authors. For a security vulnerability, use email rather than a public issue, and avoid posting exploit details, account records or credentials publicly.

Foxtopia Launcher is not an official Minecraft product and is not approved by or associated with Mojang or Microsoft. [Privacy notice](PRIVACY.md).
